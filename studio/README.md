# Paper Trails Studio

本机文档式写作台。双击项目根目录的 **写博客.cmd**，浏览器打开 http://127.0.0.1:4318/。

- 左侧选择文章，或点击“新建文章”。正文支持标题、列表、表格、图片、引用与代码。
- 工具栏 **∑** 打开可视化公式框。点击分数、根号等符号输入公式，也可展开公式键盘。双击正文里的公式可修改。支持行内与独立公式；高级用户可展开 LaTeX 源码。
- **文章设置** 中填写日期、分类、标签、摘要和草稿状态。新文章默认草稿，文件名只用英文小写、数字和短横线。
- **保存到本地** 或 Ctrl+S 将文章写入 `src/content/posts`，不上传。新插入的图片会即时写入 `public/images/uploads`。
- **发布到博客** 会保存当前文章、检查 Astro 构建并提交和上传本地文章/图片改动。先取消“草稿”才能出现在博客。GitHub 部署通常另需 1–3 分钟，可在仓库 Actions 查看结果。
- 仓库公开，上传的草稿 Markdown 也能被他人查看；私人笔记请只保存在本机。
- 同一文章被其他窗口或 Pages CMS 修改后，写作台会拒绝覆盖，需重新打开。发布遇到 GitHub 与本地版本差异时会停止，请先同步。

本服务只监听 `127.0.0.1`，无需额外账号。关闭浏览器不关闭本机服务，重启电脑后再次双击启动。备份项目时保留源码与 `studio/package-lock.json`；新电脑进入 `studio` 运行 `npm ci --ignore-scripts` 后使用。GitHub 发布依赖已有 Git/CLI 授权。

开发：`npm start`；接口验证：`npm test`。界面使用本地 Vditor 与 MathLive 资源，第三方许可见对应依赖目录。
